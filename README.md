# Program Analisis Nilai Kelas

## Deskripsi
Program untuk membaca data nilai siswa dari file, menghitung statistik nilai, menentukan ketuntasan berdasarkan KKM, dan menyimpan laporan ke file.

## Fitur
- Membaca data nilai dari file
- Validasi nilai 0-100
- Menghitung rata-rata
- Menentukan nilai minimum
- Menentukan nilai maksimum
- Menghitung jumlah tuntas dan belum tuntas
- Menyimpan laporan ke file

## Cara Menjalankan

Masuk ke folder src:

```bash
cd src
python main.py
